## 📌 **Featured Projects**

### 🔍 [Masters Thesis — Emerging Topic Detection](https://github.com/sardarm07/Masters_Thesis)
BERTopic + MiniBatchKMeans on 1.7M Civil Comments documents using transformer embeddings. Achieved C_V = 0.6847 (57% over LDA baseline), 3.01% outlier rate, and identified 10 emerging topics via composite emergence scoring. Five-method burst detection ensemble confirmed event-driven spikes tied to real-world events.

### 🫁 IMADOT — Multimodal Lung Tumor Detection
CT-PET fusion using ResNet, DenseNet, and Inception-v3 across 251K+ DICOM images from 355 patients. Published in IEEE with 98.44% accuracy.

### 👁️ Diabetic Retinopathy Detection
Fine-tuned deep learning models (ResNet, VGG-16) with attention mechanisms and ensemble learning for improved diagnostic classification.

### 🏛️ UK Parliamentary Debate Analysis
Topic modeling and sentiment analysis on 100+ years of parliamentary debates using BERTopic, LDA, BERT, RoBERTa, and VADER.
